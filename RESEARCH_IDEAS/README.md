# Research Idea Discovery (ICEEICT 2027 / journal)

Discovery-phase work only: no manuscript, no full experiment campaign. Start with `FINAL_RECOMMENDATION.md`.

| File | What it contains |
|---|---|
| `FINAL_RECOMMENDATION.md` | Direct recommendation, ranked shortlist (conference and journal), answers to the 11 questions, plan to 25 Oct, actions needed from you |
| `PROJECT_CONTEXT.md` | Repository inspection, verified 7th ICEEICT requirements (deadline 25 Oct 2026), compute and network constraints |
| `SEARCH_LOG.md` | Every significant search and access attempt, with source status (peer-reviewed / preprint / not reviewed) |
| `RESEARCH_LANDSCAPE.md` | Track-by-track landscape, saturated directions to avoid, open questions |
| `GAP_DATABASE.csv` | Structured record of 12 gaps (7 kept, 5 discarded) |
| `CANDIDATE_IDEAS.md` | Six candidates (C1–C6) with sections A–M |
| `NOVELTY_AUDIT.md` | Closest works per candidate and claim-by-claim verification status |
| `pilot/PILOT_REPORT.md` | CPU pilot of C1 (TabPFN v1) and validation of the C3 pipeline |
| `pilot/KAGGLE_RUNBOOK.md` | Ready-to-run Kaggle cells for the decisive C1 test and the C3 backup, with go/no-go rules fixed in advance |
| `pilot/*.py` | Pilot scripts (`dpa_tfm_pilot.py`, `summarize_pilot.py`, `tsfm_coherence_pilot.py`) |
| `pilot/results/` | Raw pilot outputs (JSON) and generated summary tables |

Datasets and model weights are not committed. Scripts download them from public sources (PMLB via GitHub LFS media, ETT via GitHub, TabPFN v1 checkpoint via GitHub).
